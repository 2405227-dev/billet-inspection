# BilletVision: System Architecture

## 1. Overview
BilletVision is an automated, non-contact, inline multimodal steel billet inspection and traceability system designed for continuous hot/cold rolling and casting lines.

The architecture decouples sensing, metrology, NDT simulation, data fusion, and decision-making into modular services behind strict Hardware Abstraction Layer (HAL) interfaces.

```
       [ Optical Rig (CAM-01..05) ]   [ 3D Laser Triangulation ]   [ Rotary Encoder ]
                     \                         |                         /
                      \                        |                        /
               [ Billet Detection & Continuous Tracking (Kalman / SORT) ]
                                       |
                   [ Calibrated Dimensional Metrology (px->mm) ]
                                       |
                   [ End-Face OCR & Heat / Batch Identification ]
                                       |
                   [ Multi-Scale Surface Defect Segmentation ]
                                       |
       [ Eddy Current Array (ECA) ]         [ Phased Array UT (PAUT) ]
       (Near-Surface Cracks: DEMO)          (Volumetric Core Flaws: DEMO)
                     \                         /
                      \                       /
                 [ Multi-Modal Sensor Fusion Engine ]
                                       |
                    [ Rule-Based Decision Engine ]
                  (PASS / FAIL / REWORK / NEEDS_REVIEW)
                                       |
                  [ Cryptographic SHA-256 Audit Trail ]
                                       |
                  [ Digital Billet Twin Lifecycle Store ]
                     /                         \
                    /                           \
         [ Industrial HMI (Next.js) ]     [ PLC Actuator (Modbus/OPC-UA) ]
```

## 2. Core Subsystems

### 2.1 Hardware Abstraction Layer (HAL)
- **`CameraInterface`**: 2D Optical area/line-scan camera interface.
- **`EncoderInterface`**: Physical millimeter position, velocity, and timestamp acquisition.
- **`Laser3DInterface`**: Triangulation profiling for surface topography and height maps.
- **`ECAInterface`**: Multi-channel eddy current array surface crack inspection.
- **`PAUTInterface`**: Phased array ultrasonic testing for volumetric and core flaws.
- **`PLCInterface`**: Industrial automation fieldbus communication (OPC-UA / Modbus TCP / digital I/O).

### 2.2 Metrology & Optical Processing
- Calibrated homography and perspective transformation.
- Sub-millimeter contour edge analysis with pixel-to-mm mapping.
- Tolerances configured dynamically per metallurgical product standard.

### 2.3 Non-Destructive Testing (NDT)
- Surface crack detection via 16-channel ECA impedance matrix.
- Volumetric porosity detection via PAUT acoustic echo waveforms (A-scan) and depth cross sections (B-scan).
- **Honesty Principle**: In prototype mode, all NDT streams are generated by calibrated simulators (`DemoECA`, `DemoPAUT`) and explicitly marked `SIMULATION / DEMO MODE`.

### 2.4 Sensor Fusion & Decision Engine
- Cross-correlates optical cracks, ECA impedance anomalies, PAUT core echoes, and metrology tolerances.
- Emits transparent root-cause reasoning ("Why did this billet fail?").

### 2.5 Digital Billet Twin & Audit Ledger
- Captures the complete inspection lifecycle per physical billet.
- Chains all records with SHA-256 cryptographic hashes for tamper detection.
